# Turbo-Arkanoid

A modern Arkanoid clone built with Python and Pygame.

## Controls

| Key | Action |
|---|---|
| ← → / A D | Move paddle |
| Space | Launch ball / Fire laser |
| P | Pause |
| ↑ ↓ / W S | Menu navigation |
| Enter | Confirm |
| Esc | Back to menu |

## Run

```bash
pip install pygame numpy
python3 main.py
```
